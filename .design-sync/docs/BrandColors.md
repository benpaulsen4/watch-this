# BrandColors

Reference card for the colour system — surfaces, text, accent and semantic
roles, with the `var(--wt-*)` token beside each Tailwind class.

**Don't compose with this component.** Style product screens with the classes
it documents. Surfaces step darkest → lightest (`bg-gray-950` page →
`bg-gray-900` raised → `bg-gray-800` card → `bg-gray-700` input); red is the
brand accent; the semantic set maps 1:1 onto watch statuses.
