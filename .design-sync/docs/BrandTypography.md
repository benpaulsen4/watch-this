# BrandTypography

Reference card for the type system. Geist throughout, shipped with the design
system as five woff2 subsets (variable 100–900) plus a metric-matched Arial
fallback, so text doesn't reflow while it loads.

**Don't compose with this component.** The scale is deliberately narrow:
`text-sm` is the workhorse for UI, `text-xs` for badges and metadata,
`text-xl`/`text-2xl`/`text-3xl` for headings. Weights in use are `font-normal`,
`font-medium`, `font-semibold` and `font-bold`.
